# Product Spec — Mobile Gaming Platform (working name: "bet")

> Startup artifact. Written before development began on 2026-10-13. **Not maintained** — once
> features exist, the code is the source of truth. Do not edit this file to match the code; use
> `/spec-check` to flag drift instead.

## Original brief

Build a mobile-first gaming platform inspired by 1xBet, focused on Aviator, Ludo, Chicken Road,
and Dice.

**DESIGN:** Dark blue theme, responsive mobile UI, game cards, bottom navigation, smooth
animations, original branding.

**GAMES:** Separate game interfaces and backend-controlled game logic. Aviator-style crash game,
multiplayer Ludo, Chicken Road-style progressive game, and Dice.

**ACCOUNTS:** Registration, login, profile, session security, game history, account recovery, and
verification where required.

**WALLET:** Secure transaction ledger architecture. Real-money functionality only if lawful and
approved; virtual coins for the initial free-to-play version.

**ADMIN:** User management, game configuration, monitoring, support, reporting, permissions, and
audit logs.

**TECH STACK:** Next.js, TypeScript, Node.js/NestJS, PostgreSQL, Redis, WebSockets where needed,
secure APIs, cloud hosting, backups, and monitoring.

**SECURITY:** Server-side validation, anti-cheat measures, idempotent transactions, testing,
logging, and recovery procedures.

**DELIVERY:** UI/UX prototype, core website, first game, remaining games, admin dashboard,
testing, deployment, documentation, and handover.

## Pre-development decisions (agreed with product owner, 2026-10-13)

| Topic          | Decision                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Currency in v1 | Virtual coins only. Zero cash value: cannot be purchased, withdrawn, or transferred between players.                      |
| Coin sources   | Signup bonus, periodic free refill, admin grants (audited), referral/rewards.                                             |
| Fairness       | Provably fair outcomes (server-seed commitment, player-verifiable) with an admin-configurable house edge per game.        |
| First game     | Aviator (real-time crash game), built end-to-end before the others.                                                       |
| Ludo modes     | Quick match (stake per seat), private rooms (invite code), bots fill empty seats after a timeout, play vs bots only.      |
| Sign-in        | Email + password (with verification and reset), Google sign-in, guest play (upgradeable to a full account).               |
| Age gate       | None in v1 (free-to-play). Revisit before any real-money feature.                                                         |
| Branding       | Placeholder name "bet" until branding is decided.                                                                         |
| Hosting        | Undecided. Everything is containerised; cloud chosen before deployment. Local dev must work on macOS, Windows, and Linux. |
| Repo layout    | pnpm monorepo: `frontend/` (Next.js), `backend/` (NestJS), `packages/shared/`.                                            |
| Database layer | PostgreSQL via Prisma; Redis for real-time state, pub/sub, and rate limiting.                                             |
| Branching      | Commit directly to `dev-v2` for now.                                                                                      |
